# Motion：机器人规控算法实验仓库

第一版使用 MuJoCo 3.3.7 与 Panda 七自由度机械臂，提供关节力矩驱动的
笛卡尔阻抗 + 法向导纳控制，支持恒力按压与沿面滑动。
末端为刚性杆与球形接触头，不含原装夹爪。模型来源、版本及许可见
[SOURCE.md](assets/panda/SOURCE.md)。

## 安装与运行

需要 Python 3.12、uv 和 Git。在仓库根目录执行：

```bash
export UV_CACHE_DIR="$PWD/.cache/uv"
uv sync --frozen
uv run --frozen motion --task press
uv run --frozen motion --task slide --force 10 --distance 0.06
uv run --frozen pytest -q
```

默认无界面运行，不需要 GPU 或图形上下文。WSL2/WSLg 或本地桌面可以打开窗口：

```bash
uv run --frozen motion --task slide --viewer
```

云环境 GUI 尚未验证。用户此前已验证其本地 WSL 和 Docker 能打开空 MuJoCo
查看器；Panda 场景仍需在本地实际运行验证。

## 结果与验收

每次实验在 runs/ 下创建唯一目录，包含：

- trace.csv：时间、TCP/目标位置、接触力、腕部六维原始测量、关节状态及控制力矩。
- metrics.json：末段力误差、峰值、接触保持率、位置误差及滑动距离。
- metadata.json：完整配置、模型来源版本、软件版本、Git 提交号与工作区状态。

可用 --output 指定目录，但不能覆盖已有目录；可用 --timestep 0.0005 减半步长。
默认 8 秒、1 ms 物理与控制周期、10 N 目标力、60 mm 滑动距离。
支持 0–20 N（不含 0），时长至少 4 秒。

命令返回非零状态表示未通过基线阈值：末秒力 RMSE < 1.5 N、峰值 < 2 ×
目标力 + 5 N、接触保持率 > 95%、最终 XY 误差 < 5 mm。这些仅为演示任务的
回归阈值，不是实际插装或打磨精度要求。

## 模型与测量限制

- 世界坐标 +Z 向上，接触力是工件作用于工具的力，单位 N。
- 腕部原始六维力/力矩以 wrist site 表达，单位 N / N·m，包含工具重力和惯性。
  当前反馈使用引擎的理想接触力，并未使用去重力后的腕部测量。
- 模型保留自碰撞、关节约束，关节驱动力矩限制为 87/87/87/87/12/12/12 N·m。
- 工作台自动放在初始 TCP 下方 15 mm，不是标定工位。
- 尚无执行器带宽/延迟、传感器噪声、加工材料去除或实机参数标定。
- seed 仅为配置预留，未启用随机扰动。
- 插装、人形、步态调度未实现，见 [路线图](docs/roadmap.md)。

当前按源码检出 + editable 安装使用，模型从源码目录加载，不支持把 wheel
脱离源码目录独立运行。
